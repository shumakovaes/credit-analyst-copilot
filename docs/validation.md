# Протокол выполненных проверок

Дата: 5 ноября 2026. Проверены Windows (Python 3.12.14, PostgreSQL 17) и Linux-контейнеры в Docker Desktop. Docker Engine 27.3.1, Compose 2.30.3-desktop.1. Зависимости — `requirements.lock`. Тестовые базы отделены от баз приложений: локально `credit_copilot_test`, в Docker `copilot_test`.

## Результаты

- **58 тестов пройдены, пропусков нет.** [JUnit-отчёт](../reports/test-results.xml).
- Политика отклоняет DML/DDL, несколько выражений, writable CTE, SELECT INTO/FOR UPDATE, системные и чужие схемы, небезопасные функции, обходы через CTE/UNION, рекурсию, неограниченные LIMIT и другие неподдерживаемые конструкции.
- Reader-роль не может удалить строки даже после явного `SET TRANSACTION READ WRITE`. Отдельно проверены read-only по умолчанию и отказ исполнителя использовать администратора.
- Проверены усечение результата, ограничение стоимости плана, серверный statement_timeout и запрет нечисловых значений NaN/Infinity в JSON-результате.
- Агент исправляет неизвестный столбец до выполнения и настоящую ошибку группировки после ответа PostgreSQL. Цикл останавливается после третьей попытки; запрещённый SQL прекращает обработку сразу.
- Проверены адаптеры Chat Completions и Responses: структура запроса, JSON Schema, обработка ошибок/таймаутов и отсутствие секретов в сообщениях. Использован подменённый HTTP-транспорт, не реальные вызовы LLM.
- Проверены API, история, изоляция контекста диалогов, экспорт, экранирование CSV-формул, уточнение и последующий вопрос, все три страницы через Streamlit AppTest.
- 12/12 демосценариев eval выполнены; восемь дополнительных live-сценариев пропущены. [Отчёт](../reports/evaluation.json) явно помечен `llm_quality_measured=false`.
- Подключение к первому проекту проверено через отдельные представления: 682 кредита, сумма при выдаче 103 261 740 CZK. Прямой SELECT из `clean.loans` от reader-роли отклонён. [Протокол](../reports/risk-desk-integration.json).
- Через настоящий HTTP API выполнен подготовленный сценарий исправления SQL; [полный журнал](../reports/repair-demo.json). Сохранена [OpenAPI-спецификация](../reports/openapi.json).
- В headless Chrome проверены чат, таблица, график, раскрытие SQL/шагов и отказ для DELETE. Ошибок JavaScript не обнаружено. Скриншоты просмотрены визуально: [чат](../reports/copilot-chat.png), [журнал](../reports/copilot-trace.png), [проверка SQL](../reports/copilot-policy.png). [Browser report](../reports/browser-check.json).
- Повторная инициализация вернула `already_initialized`, данные не заменены. `compileall` и `docker compose config --quiet` прошли.
- Создан отдельный локальный Git-репозиторий. `.env`, runtime-журнал и окружение исключены из Git и архива исходников.

## Дополнительно проверено в Docker

- Собраны образы init, API и UI. База `copilot`, API и Streamlit работают со статусом `healthy`; init успешно завершился с кодом 0.
- **58/58 тестов пройдены внутри Linux-контейнера**, без пропусков. Интеграционные тесты используют отдельную контейнерную PostgreSQL-базу `copilot_test`. [Docker JUnit](../reports/docker-tests.xml).
- Повторная оценка дала 12/12 успешных демосценариев, 8 live-сценариев пропущены; качество LLM этим не измерено. [Docker eval](../reports/docker-evaluation.json).
- Проверен доступ из контейнера Copilot к контейнерной базе Risk Desk через `host.docker.internal:5433`: 682 кредита и 103 261 740 CZK. Reader имеет доступ к разрешённым представлениям; прямое чтение `clean.loans` отклонено. [Протокол Docker-интеграции](../reports/docker-integration.json). Основное приложение оставлено на самостоятельной синтетической базе.
- Три прежние записи журнала перенесены из согласованной SQLite-копии в постоянный Docker-том; наличие всех исходных ID подтверждено.
- Через опубликованные порты проверены HTTP health, чат, таблица, график, SQL/журнал и отказ для DELETE в Chrome. Скриншоты и browser report обновлены; ошибок JavaScript нет.
- Добавлены healthcheck UI и `restart: unless-stopped` для постоянно работающих сервисов. [Сводный Docker-протокол](../reports/docker-validation.json).

## Не проверено

- Живое обращение к LLM и смысловое качество генерации SQL: ключа провайдера в окружении нет. Числа accuracy для LLM не заявляются.
- GitHub Actions: workflow подготовлен, но удалённый репозиторий не опубликован и CI на GitHub не запускался.
- Независимый аудит безопасности, публичное размещение, многопользовательские права и нагрузочные испытания не выполнялись.
