# Повторная проверка перед демонстрацией

Дата: 5 ноября 2026. Проверены свежая установка, сохранение журнала, SQL-ограничения, обработка некорректного ввода и CSV-экспорт.

## Найдено и исправлено

- Нечисловой вопрос с JSON-значением `NaN`/`Infinity` вызывал ошибку сериализации ответа валидации и HTTP 500. Теперь API возвращает HTTP 422 без отражения исходного значения.
- CSV экранировал формулы в строках, но не в заголовках. Модель могла задать SQL-псевдоним `=1+1`, который попадал в экспорт как формула. Теперь заголовки также экранируются. Регрессионный тест проходит весь путь: SQL-план → PostgreSQL → журнал → CSV; числовой результат сохраняется.

## Дополнительные проверки

- Свежий clone коммита `ce2d6e20ef25f0f2a2b3e040fce46dae6da55857` собран в отдельном Compose-проекте `review-copilot`, без `.env` и локального журнала. Изменены только внешние порты. Инициализированы 24 синтетических кредита; UI и API доступны.

- Проверены глубоко вложенные скобки, длинная цепочка условий, CTE, скрывающие имя таблицы, рекурсивный CTE, вложенный UNION с системной таблицей, слишком длинный литерал, кавычки в именах и приведение к системному типу. Запрещённые запросы отклонены контролируемо; разрешённые конструкции прошли. Каждый отдельный процесс завершился менее чем за секунду.
